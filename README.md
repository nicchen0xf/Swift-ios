## 📱 Sideload Installation Guide

### Option 1: TrollStore (Recommended — Permanent / No Revokes)
1. Download `ByteExternal_V1.1.1.ipa` on your iOS device via Safari.
2. Tap the downloaded file in Safari Downloads and select **Share** -> **TrollStore**.
3. TrollStore will install and sign the binary permanently without 7-day expiration.

### Option 2: Scarlet / ESign (Direct on Device)
1. Open Scarlet or ESign on your iOS device.
2. Tap the Import/Install icon in the top navigation.
3. Select `ByteExternal_V1.1.1.ipa` and confirm installation.

### Option 3: SideStore / AltStore (Computer / Wi-Fi)
1. Connect device or ensure SideStore/AltStore VPN is active.
2. Open the **My Apps** tab and tap the **+** button.
3. Select `ByteExternal_V1.1.1.ipa` to sign and install with your Apple ID.
